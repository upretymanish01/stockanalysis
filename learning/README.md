# Learning

Place for continuous learning related to stock analysis, quantitative methods, risk, and related topics.

## How to use
- Add a new Markdown note for each topic, concept, paper, video, or session.
- Name files clearly, e.g. `gbm-basics.md`, `var-cvar.md`, `2026-11-21-monte-carlo-session.md`.
- Keep notes short and practical — what you learned + how you might apply it.
- Move any reusable code into `src/` once it stabilizes.

## Suggested structure
```
learning/
├── README.md
├── concepts/          # theory, formulas, mental models
├── sessions/          # dated learning sessions or reviews
├── papers/            # notes from papers or books
└── ideas/             # raw ideas to explore later
```

You can keep it flat if you prefer — just drop `.md` files directly in `learning/`.
